# CSE423 - Software Architecture Assignment
Software Architecture Structure Analysis Assignment - Design Pattern Preservation

## Task 2: Design Pattern Preservation

This repository contains the selected source files, project descriptions, and file descriptions for **Spring PetClinic**, which is used for **Task 2: Design Pattern Preservation** in the CSE423 Software Architecture course.

The objective of this task is to evaluate whether a Large Language Model (LLM) preserves object-oriented design patterns when reconstructing an existing software system.

---

## Selected Repository

### Spring PetClinic

**Original Repository:**
https://github.com/spring-projects/spring-petclinic

**Language:**
Java (Spring Boot)

**Description:**
Spring PetClinic is a sample Spring Boot application for managing a veterinary clinic. It follows a layered architecture and demonstrates several object-oriented design principles. For this assignment, it is used to analyze the preservation of design patterns after LLM-based reconstruction.

---

## Assignment Objective

The purpose of this repository is to:

- Select a software project that uses object-oriented design patterns.
- Identify the design patterns used in the original system.
- Compare the original project with an LLM-generated reconstruction.
- Evaluate whether the design patterns are preserved.
- Prepare the project for Design Pattern Preservation analysis.

## Design Patterns Analyzed

The selected files are intended to support the analysis of the following design patterns:

- Singleton Pattern
- Factory Pattern

These patterns will later be compared with the LLM-generated implementation to calculate:

- Pattern Preservation Rate (PPR)
- Pattern Collapse Rate (PCR)
- Abstraction Loss Score (ALS)
