# VetClinic Backend File Descriptions

## VetClinicApplication.java
The main Spring Boot application class generated by the LLM. It initializes the Spring application and starts the embedded server.

---

## OwnerController.java
Handles HTTP requests related to owner management.

---

## PetController.java
Handles HTTP requests related to pet management.

---

## OwnerRepository.java
Provides data access operations for Owner entities.

---

## PetRepository.java
Provides data access operations for Pet entities.

---

## Owner.java
Represents the Owner entity.

---

## Pet.java
Represents the Pet entity.

---

## Vet.java
Represents the Veterinarian entity.
